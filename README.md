# Clocks / 钟

一个小小的钟表实验室。这里收集的不是实用时钟，而是一些关于“时间还能怎样被看见、被误读、被重新编码”的练习。

A small clock laboratory. The clocks here are not meant to be practical; they are exercises in how time can be seen, misread, and encoded differently.

这个项目主要是我用于消遣、试验想法、以及消耗自己多余精力的地方。它会随时增删、归档、重做；没有宏大的路线图，也不保证每个想法都会留下来。

This is a personal project for leisure, experiments, and spending my surplus energy. Clocks may be added, removed, archived, or rebuilt at any time; there is no grand roadmap, and not every idea is meant to stay.

## Design Philosophy / 设计理念

这里的“钟”不一定以现代 HH:MM 的可读性为第一目标。一个表盘如果选择了另一套时间系统，就应该让观看者进入那套系统，而不是把一切都翻译回普通钟表。

The clocks here do not always optimize for modern HH:MM readability. When a clock commits to another time system, it should let the viewer enter that system instead of translating everything back into ordinary clock time.

好的表盘不是“又一种编码”，也不是同一个结构换一层材料、换一个文化对象、加一个对得上数字的维度。它应该有不可替代性：这个时间经验必须自然长成这个形式。

A good clock is not merely another encoding, nor the same structure with a new material, cultural object, or numerically convenient dimension. It should feel non-substitutable: this experience of time should naturally require this form.

钟表也不应以任何方式依赖观看者主动发生互动。观看者可以停留、凝视、读懂或误读，但表盘不能以点击、拖动、悬停、输入或设置作为成立条件。它必须在无人触碰时仍然完整地运行和表达。

A clock should also never depend on active viewer interaction. The viewer may linger, gaze, understand, or misread, but the dial should not require clicking, dragging, hovering, input, or configuration in order to work. It must keep running and expressing itself untouched.

所以这个项目不把“系列挖掘”当作默认的创作方法。算盘表之后再做结绳表，纸表之后再做玻璃表，如果没有新的必要性，就只是换皮。真正有价值的跳跃，是从圆形表盘跳到算盘表那样：一种新的读法、一具新的身体、一个新的时间经验同时出现。

So this project does not treat “series mining” as a default method. A knot-counting clock after a soroban clock, or a glass clock after a paper clock, is only a reskin unless it has its own necessity. The valuable leap is more like moving from a round dial to the soroban clock: a new reading method, a new body, and a new experience of time arriving together.

技术复杂度不是好坏的核心。一个简单的设计也可以成立，只要它有足够的意味和形式必然性。Sleep 是这个项目的重要参照：它不是炫技，而是在夜里温柔地撤走时间，提醒你这段时间不必关心钟表；被挖掉的夜晚也让表盘接近一弯月亮。

Technical complexity is not the main measure of quality. A simple clock can be strong if its meaning and form are necessary. Sleep is an important reference point for this project: it is not a technical showpiece, but a gentle removal of time at night, a reminder that this is a span in which you should not need to care about clocks; the missing night section also makes the dial resemble a moon.

比起第一眼的新奇，这个项目更在乎一个表盘能不能经得起反复观看：它是否仍然温柔、准确、奇怪、必要；是否真的改变了你理解时间的方式。

More than first-glance novelty, this project cares whether a clock can survive repeated viewing: whether it remains tender, precise, strange, and necessary; whether it actually changes how time can be understood.

如果这个项目最终走向 60 个表盘，那也不是为了凑数。60 是钟表自己的数字；每一个位置都应该争取成为一种值得留下的看时间方式。

If the project eventually grows toward 60 clocks, that number is not a quota. Sixty is the clock’s own number; every slot should try to become a way of seeing time that deserves to stay.
